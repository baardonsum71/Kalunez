## 1. Executive summary


Kalunez is a **production-ready** virtual concert and music streaming platform. It was built so artists can upload music, go live, connect with fans, and monetize via **Stripe subscriptions** and **Connect tips**.


The product is **live at www.kalunez.com**, fully documented, and tested in Stripe sandbox. There are **no users, no marketing spend, and no revenue** — the seller is transferring a completed asset to a buyer with go-to-market capability.


**Included in sale:** domain (kalunez.com), GitHub codebase, Base44 backend app, brand, documentation, seller handover support.

## 4. Stripe monetization workflow


### Subscriptions (listeners)

1. User visits `/pricing` → selects plan

2. Frontend calls `createCheckoutSession` (Base44 function)

3. Stripe Checkout session created → redirect

4. On payment: `handleStripeWebhook` receives events

5. `Subscription` entity + user tier updated


**Test verified:** Sandbox checkout with card `4242…` → success page displayed.


### Artist tips (Connect)

1. Artist completes Connect onboarding (`createConnectAccount`)

2. Fan clicks Tip → `createTipCheckout`

3. 90% to artist / 10% platform fee

4. Webhook records `Tip` entity


**Secrets (Base44):** `STRIPE_API_KEY`, `STRIPE_WEBHOOK_SECRET`, `STRIPE_ALLOWED_PRICES`, `BASE44_APP_URL`


**Docs:** `docs/STRIPE.md`
