# Framtidspitch — Kalunez till svensk DJ / programledare

Öppna den visuella pitchen: [`PITCH_DJ_SV.html`](./PITCH_DJ_SV.html) (dubbelklicka eller `open docs/PITCH_DJ_SV.html` på Mac).

## Positionering (30 sekunder)

**Kalunez** är en musik- + liveplattform du kan äga. Du har redan publiken (TV4, YouTube, community). Appen ger dig stället där fans streamar, tittar live, köper biljetter och abonnemang — och där du styr reklamytor och format.

## Varför just du

| Tillgång | Vad Kalunez ger dig |
|----------|---------------------|
| Programledare i svensk TV (bl.a. TV4) | Länkblock / “sett på TV4” på sajten; betald synlighet när avtal finns |
| Nominerad Årets programledare (*Spökjakt*, TV4) | Troverdighet + PR i pitch och på sajt |
| Stor YouTube-följarskara | Fast kanallänk, cross-promo lives ↔ YouTube |
| Designkläder & gear | Partner-/merch-sektion **endast med tillstånd** |
| Showman / DJ | **Song Challenge** med snurrande hjul + premie |

## Intäktsvägar (framtid under ditt ägarskap)

1. **Abonnemang & biljetter** — iOS/Android IAP + livebiljetter (befintligt produktspår).
2. **TV4-relaterad synlighet** — länkar och sponsorplaceringar på sajten (avtal + ersättning till dig).
3. **YouTube** — trafik och eventuell betald promo för klipp/kanal.
4. **Stil / gear** — affiliate eller kampanjfee med skriftligt OK från märken.
5. **Song Challenge** — återkommande event: hjulet väljer låtar → match → stark premie (gärna sponsrad).

## Song Challenge (produktidé)

- Du skapar challenge-match.
- Hjul snurrar och landar på låtar att tävla om.
- Live (chat/röster) avgör vinnare.
- Premie: kontant, gear, merch, studio, live-slot, etc.
- Replay → YouTube → tillbaka till Kalunez.

> Hjulet i HTML-pitchen är en **demo**. Feature byggs när du tar över (eller som del av deal).

## Demo-ordning (5–7 min)

1. Hem / Discover — musik + live.
2. Live / Go Live — din scen.
3. Pricing — Premium Monthly (IAP).
4. Artist-ytor — dashboard-tänk.
5. Öppna `PITCH_DJ_SV.html` — snurra hjulet, prata TV4 / YouTube / stil.

## Ärlighet

- Påstå **inte** App Store / Play-godkännande förrän det är sant.
- Reklam för TV4, YouTube och klädmärken kräver **avtal / tillstånd**.
- Pitcha som **ägarbara tillgångar + roadmap**, inte som färdiga sponsoravtal.
